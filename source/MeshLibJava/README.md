# MeshLib Java bindings

Generated by [mrbind](https://github.com/MeshInspector/mrbind) from the C bindings, on top of the foreign function API of Java 22. Nothing in this directory is committed except this file:

```sh
make -f scripts/mrbind/generate.mk TARGET=c      # The C bindings and their description JSON.
make -f scripts/mrbind/generate.mk TARGET=java   # The Java sources in `src`, the classes in `classes`, and `meshlib.jar`.
```

To use the bindings, put `meshlib.jar` on the class path, and the MeshLib shared libraries (including `MeshLibC2`) into `java.library.path`:

```sh
java --enable-native-access=ALL-UNNAMED -Djava.library.path=build/Release/bin -cp source/MeshLibJava/meshlib.jar:. MyProgram
```

See `examples/java-examples` and the tests in `source/MRTestJava`.
